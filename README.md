# Pompompurin Café - Aplicación Web en Flask

## Cómo ejecutar
1. Descomprime `pompompurin_cafe_v2.zip`.
2. Abre una terminal dentro de la carpeta `pompompurin_cafe`.
3. Instala Flask si no lo tienes: `pip install flask`
4. Ejecuta: `python app.py`
5. Abre `http://127.0.0.1:5000` en tu navegador.
